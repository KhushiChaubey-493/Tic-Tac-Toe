# Tic-tac-toe 

A classic Tic Tac Toe game built with HTML, CSS, and JavaScript. The project provides a simple and interactive two-player gaming experience directly in the browser.

📌 Overview

This project is a browser-based implementation of the traditional Tic Tac Toe game.

It was built to practice JavaScript game logic, DOM manipulation, event handling, conditional logic, and user interaction.

✨ Features

- Two-player gameplay
- Interactive game board
- Automatic turn switching between players
- Win detection
- Draw detection
- Game result display
- Restart / reset game functionality
- Responsive user interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM Manipulation
- Event Handling

🎮 How to Play

1. Player 1 starts the game.
2. Players take turns placing their symbol on an empty cell.
3. The first player to get three matching symbols in a row, column, or diagonal wins.
4. If all cells are filled without a winner, the game ends in a draw.
5. Use the reset button to start a new game.

⚙️ How It Works

The game uses JavaScript to:

- Track the current player's turn
- Detect user clicks on the game board
- Update the board dynamically
- Check winning combinations
- Detect draw conditions
- Reset the game state
